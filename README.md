# Globe-Trotter-for-odoo-hackathon-
Globe Trotter is a full-stack travel planning platform that empowers users to design customized multi-city itineraries, manage budgets, discover activities, and share their journeys. Built with Flask, SQLAlchemy, and Bootstrap.
Empowering Personalized Travel Planning
Globe Trotter is an interactive, end-to-end web application designed to simplify the complexity of organizing multi-city trips. The platform provides travelers with intuitive tools to visualize daily timelines, automatically track estimated expenses, and explore new destinations. Built with a focus on user-centric design, Globe Trotter helps users organize personalized trips efficiently, make cost-effective decisions, and share their travel plans with a wider community.
